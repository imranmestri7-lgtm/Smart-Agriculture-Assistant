# Phase 4 — AgriSmart Farming Chat Assistant

## Implemented

- Authenticated `POST /api/chat/message` Flask endpoint.
- JWT authentication using the existing token helper.
- Input validation for missing, empty, and oversized messages.
- Rule-based guidance for crop selection, irrigation, plant disease,
  weather, fertilizer, pest management, and market-price questions.
- Farmer chat frontend integration with loading and error handling.
- Unit tests for authentication, validation, and farming response categories.

## Limitations

- Responses are rule-based, not generated by a large language model.
- The chatbot does not retrieve live weather or market prices itself.
- Crop and treatment advice is general guidance and should be confirmed
  with local agricultural experts.
- Chat messages are not saved to a database by this implementation.

## Endpoint

`POST /api/chat/message`

Headers:

`Authorization: Bearer <access_token>`

JSON body:

`{"message": "How should I manage irrigation?"}`

Successful response includes `status`, `reply`, and `category`.
