🔌 ESP32 & Arduino Integration Specifications

Hardware microcontrollers can transmit telemetry directly to AgriSmart via HTTP/HTTPS POST without exposing farmer accounts or database credentials.

Endpoint: POST /api/iot/ingest
Headers: 
Content-Type: application/json
X-Device-Id: <YOUR_REGISTERED_DEVICE_ID>
X-Device-Key: <YOUR_SECRET_DEVICE_KEY>
Sample Soil Moisture JSON Payload: 
{
  "device_id": "ESP32-SOIL-01",
  "sensor_type": "soil_moisture",
  "value": 34.5,
  "unit": "%",
  "timestamp": "2026-10-31T09:50:00Z"
}
Sample Combined DHT22 Payload: 
{
  "device_id": "ESP32-DHT22-01",
  "readings": [
    {"sensor_type": "air_temp", "value": 28.5, "unit": "°C"},
